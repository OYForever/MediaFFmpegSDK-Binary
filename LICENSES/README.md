# 第三方许可证

更新时间：2026-11-19 09:41:09 +0800

本目录保存随源码与二进制发行包交付的许可证原文：

- `FFmpeg-LGPL-2.1.txt`：FFmpeg 默认 LGPL 2.1 或更高版本条款。
- `FSPlayer-LGPL-2.1.txt` 与 `FSPlayer-NOTICE.txt`：FSPlayer 1.1.3 的 LGPL 2.1 或更高版本条款与上游 NOTICE。
- `OpenCORE-AMR-Apache-2.0.txt`：OpenCORE AMR Apache 2.0 条款。
- `OpenCORE-AMR-NOTICE.txt`：OpenCORE AMR 上游 NOTICE。

启用的外部编解码依赖、固定版本和源码地址见根目录 `THIRD_PARTY_NOTICES.md`。最终发行包中的 `BUILD_MANIFEST.txt` 记录实际构建参数和源码/二进制哈希。

`dependencies/` 保存启用的第三方依赖随上游发布的许可证、版权与专利声明。每组文件与固定源码 URL 及归档 SHA-256 对应。打包会核对活跃依赖、来源和原文的 SHA-256。 [来源清单](dependencies/sources.tsv) · [原文指纹](dependencies/CHECKSUMS.txt)

完整对应源码、SDK 修改和重新链接材料随正式版本提供。[下载说明](../README.md)
